# ⌨️ 3D Mechanical Keyboard Customizer & ASMR Sound Simulator (Three.js + Web Audio API)

An interactive **3D Mechanical Keyboard Studio** powered by **Three.js (WebGL 2.0)** and the **Web Audio API**. Test real-time mechanical switch acoustics (Clicky, Tactile, Linear), customize keycap color palettes, toggle RGB underglow modes, and press real keyboard keys to animate 3D keycaps at 60 FPS.

📦 **[Download Complete Source Code (.ZIP) & Docs](https://newtechportal.com/projects/3d-mechanical-keyboard-sound-simulator)**

## ✨ Key Features
- **Real-Time Web Audio Switch Synthesis:** Synthesizes crisp mechanical keystroke sounds locally with zero audio file lag.
- **Interactive 3D Keycaps & RGB Lighting:** Type on your physical keyboard or click keys in 3D space with animated travel depth and customizable RGB glow.
- **Zero-Build Frontend Setup:** Self-contained HTML5, Tailwind CSS, and ES6 JavaScript — opens cleanly in any modern browser.
- **360° Camera Orbit & Mobile Support:** Inspect every angle of the 3D keyboard on desktop or mobile touch screens.
